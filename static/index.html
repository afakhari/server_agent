    مداخله پیشنهادی

    نیازمند تأیید انسانی
    تأیید مخصوص همین عملیات
    برای تأیید، نام پروژه را دقیقاً وارد کنید. مجوز سه دقیقه اعتبار دارد و فقط یک‌بار قابل استفاده است.

    Project Scout · بررسی آمادگی استقرار

    Read-only

    بدون اجرای کد ناشناس، از روی فایل‌های تنظیمات، نوع پروژه، پورت و نام متغیرهای موردنیاز شناسایی می‌شود. برای مشاهده نمونه FastAPI، گزارش را باز کنید.

    استقرار هدایت‌شده · آزمایشگاه لیارا

    فقط پروژه آزمایشی مجاز

    ابتدا تحلیل سورس و شناسه پلن را بررسی کنید. ساخت پروژه و انتشار هزینه‌زا است و فقط با تأیید صریح اجرا می‌شود. قیمت پلن در این نسخه اعتبارسنجی نشده است.

    دامنه، SSL و وضعیت انتشار

    Liara API · فقط خواندن

    وضعیت واقعی دامنه و گواهی و انتشارها را بررسی می‌کند. رکورد DNS را فقط نمایش می‌دهد؛ تغییر در پنل ثبت‌کننده دامنه بر عهده کاربر است.

    برای مشاهده داده‌های واقعی ابتدا حالت Live و شناسه پروژه را انتخاب کنید.
    Prototype v0.2 · منطق تشخیص پیش‌فرض مبتنی بر قواعد قابل‌توضیح است. این نسخه جایگزین سیستم‌های پایش و بازیابی تولیدی نیست.
