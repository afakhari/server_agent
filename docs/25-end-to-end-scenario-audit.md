## اصلاحات کلیدی در این دور
- Auth: به‌جای استنتاج mode از وجود key، actor هر مجوز/تاریخچه با mode ثبت‌شده تطبیق داده می‌شود. به‌خصوص محیط Demo در تیم‌ها.
- Persistence: تازه‌ترین ۲۵۰ پیام؛ رکورد chat_requests با کلید مرکب actor + request_id، hash درخواست و نتیجه ذخیره‌شده؛ replay مشکوک رد می‌شود.
- Transactions: مجوزهای قبلی به محض شروع turn جدید، در جدول approvals واقعاً مصرف/لغو می‌شوند. این رفتار حتی legacy /api/approve را محدود می‌کند.
- Concurrency: پردازش turn در یک process به‌ترتیب سریال است؛ multi-worker هنوز پشتیبانی‌شده نیست.
- Source: جلوگیری از قراردادن credentials، رشته اتصال، فایل حساس، تنظیمات تأییدنشده liara.json و فایل symlink تغییرکرده در آرشیو.
- Privacy: پیام‌های محتوی الگوهای شناخته‌شده credential، چه در Backend چه در نمایش کلاینت، پاکسازی می‌شوند. این DLP جامع نیست.
- UX: قابلیت واقعی planning از /api/config دریافت می‌شود؛ نمایشی/readonly نباید به‌عنوان امکان انتشار تظاهر کند.

## آزمون‌های قابل اجرا
از ریشه پروژه در محیط مجازی:

    python -m pytest -q tests/test_end_to_end_scenarios.py tests/test_package_safety.py tests/test_conversation.py tests/test_intent_experience.py
    python -m pytest -q

فرانت‌اند:

    cd frontend
    npm ci
    npm run build

پیش از استقرار روی VPS با فایل‌های خصوصی معتبر:

    python scripts/check_server_release.py
    docker compose -f compose.server.yaml config --quiet
    docker compose -f compose.server.yaml build

## شکاف‌های باز برای پذیرش نهایی
1. تست واقعی مرورگر برای ذخیره history پس از SSE قطع‌شده، تغییر پروژه و تایید قدیمی. UI هنوز برای تغییر پروژه در چت قبلی الزاماً reset خودکار نمی‌کند؛ backend به‌طور امن رد می‌کند و کاربر باید New Chat انتخاب کند.
2. npm lockfile در شاخه GitHub هنوز ثبت نشده؛ دریافت registry از محیط این بررسی موفق نشد. تولید و commit آن در دستگاه اپراتور لازم است.
3. GitHub Actions اجراهای گذشته را بدون گام اجرا‌شده failed ثبت کرده است؛ سبزشدن تست‌ها ادعا نمی‌شود.
4. نرخ‌دهی edge/Basic Auth، مدیریت هویت چندکاربره، کنترل DNS rebinding و آزمون نفوذ برای استقرار عمومی هنوز لازم‌اند.
5. سناریوی live-read و live-write فقط با حساب disposable، توکن مالک و شواهد redacted معتبر می‌شود؛ اینجا اجرا نشده است.
6. ویدیوی حدود پنج دقیقه چالش همچنان الزامی و ضبط‌نشده است.
